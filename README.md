# 微信视频号视频下载器 (WeChat Channels Downloader)

一个用于**备份自己在微信中可以观看的视频号视频**的 Windows 桌面应用。
打开视频号播放视频 → 点一下悬浮按钮 → 得到可直接播放的 MP4。

## 与旧版的区别（重要）

旧版是一个命令行脚本，工作方式是**接管系统代理 + 安装 mitmproxy 根证书**来解密 HTTPS 流量。这带来三个副作用：

- 全机器的流量都被拖进代理
- 需要往系统里装一张中间人根证书
- 会和 Clash / 其他代理软件抢同一个系统代理开关

**新版把这一整套全部拆掉了。** 视频的真实 CDN 地址和解密种子本来就明文躺在视频号播放器自己的进程内存里，直接读出来即可：

```
读取微信进程内存
    │  拿到 https://finder.video.qq.com/.../stodownload?encfilekey=... 和 decode_key
    ▼
curl 下载完整文件
    │  仅前 128KB 被 Isaac64 密钥流 XOR 加密
    ▼
微信官方 WASM 模块生成密钥流 → 解密 → 可播放的 MP4 ✅
```

因此：

| | 旧版 | 新版 |
|---|---|---|
| 系统代理 | 接管全局 | **完全不碰** |
| 根证书 | 安装 mitmproxy CA | **不安装** |
| 对 Clash 的影响 | 冲突 | **无** |
| 网络特征 | 全流量经过 | **无流量中转** |
| 交互方式 | 命令行 | 桌面窗口 + 悬浮按钮 |

## ✨ 特性

- 🖱️ **悬浮下载按钮**：常驻屏幕右侧，可拖到任意位置，播放时点一下即可
- 🔒 **零网络劫持**：不改系统代理、不装证书、不影响任何其他软件
- 🔓 **自动解密**：Isaac64 PRNG + XOR（仅文件前 128KB），使用微信官方 WASM 模块保证与播放器行为一致
- 🔗 **失效链接自动跳过**：内存里存着大量历史链接，会逐个探测，挑还活着的那一条
- 🧹 **退出即净**：无后台代理常驻，不留网络副作用

## 🚀 安装

### 方式一：安装包

从 Releases 下载 `视频号下载器_安装包_x.y.z.exe`，双击安装。会在桌面和开始菜单创建快捷方式。

### 方式二：从源码运行

```bash
git clone https://github.com/my832/wechat-channels-downloader.git
cd wechat-channels-downloader
npm install
npm start
```

### 打包成安装程序

```bash
npm run dist            # 生成 dist/视频号下载器_安装包_x.y.z.exe
```

## 📖 使用

1. 在微信里打开视频号，**点开要下载的视频并让它播放**
2. 保持播放器窗口打开（解密种子只存在于播放期间的内存中）
3. 点屏幕右侧的**悬浮按钮**，或主窗口的「下载当前视频」
4. 等待 15~30 秒，MP4 会保存到 `C:\Users\<你>\Videos`

默认输出目录可在主界面修改。

## ❓ 常见问题

**提示「微信内存里没有找到视频地址」**

- 确认微信 PC 版已登录且视频号能正常打开
- 视频必须**处于播放状态**，不要先关掉播放器窗口
- 如果是看过的视频，拖一下进度条再试

**提示「链接都已失效」**

内存里可能只剩历史残留。重新点开该视频播放几秒，然后**立刻**点下载。

**提示「没有验证出解密种子」**

`decode_key` 存在播放器进程内存里，窗口一关就没了。保持播放器窗口打开后重试。

**杀毒软件报警**

本工具会读取微信进程内存（`ReadProcessMemory`），部分安全软件会敏感。这是功能必需，不涉及任何网络上传。

## 🔧 工作原理

1. **定位进程**：`WeChatAppEx.exe`（视频号播放器，Chromium 内核）
2. **扫描内存**：在可读区域搜索 `stodownload`，用正则提取完整 CDN 链接与 `decode_key`
3. **去重排序**：按 `encfilekey` 归并同一条视频的分段链接，优先播放器进程、最近分配的地址
4. **探测有效性**：对候选链接发 Range 请求拉前 1KB，跳过已过期或内容异常的
5. **下载**：`curl` 拉完整文件（视频号 CDN 返回 206 分段）
6. **解密**：把 `decode_key` 喂给微信官方 `wasm_video_decode` 模块生成 Isaac64 密钥流，反转后 XOR 前 128KB
7. **落盘**：写出 `_完整.mp4`
